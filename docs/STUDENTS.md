# ShapeForge — Quick start for students

## Open the app

1. Double-click **ShapeForge** on the desktop (or Start Menu).
2. You will see a dark workplane with a grid.

## Make your first model (5 minutes)

1. On the left, click **Box**. A blue box appears.
2. Click **Move** at the top (or press `G`). Drag the colored arrows.
3. Click **Cylinder**, move it so it overlaps the box.
4. With the cylinder selected, click **Hole**.
5. Turn **Cuts: On** (top-right of the 3D view) to see the hole cut through the box.
6. Click **Export STL** and save the file for the 3D printer.

## Useful buttons

| Button | What it does |
| --- | --- |
| Move / Rotate / Scale | Change the selected shape |
| Hole | Make the shape cut through solids |
| Duplicate | Copy the selection |
| Undo / Redo | Fix mistakes |
| Snap | Keep sizes neat on the grid |
| Save / Open | Keep your project on this computer |
| Export STL | Send to a slicer / printer |

## Keyboard shortcuts

- `G` Move · `R` Rotate · `S` Scale
- `Ctrl+Z` Undo · `Ctrl+Y` Redo
- `Ctrl+D` Duplicate · `Delete` Remove

## Tips

- Keep **Snap** on while learning.
- Holes are pink and see-through.
- Name your project at the top before you Save.
